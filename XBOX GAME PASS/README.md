# Xbox Game Pass — Subscription Sales Dashboard

## Sobre o projeto

Este projeto tem como objetivo analisar as vendas de assinaturas do **Xbox Game Pass**, utilizando o Microsoft Excel para organizar dados, desenvolver análises e construir um dashboard interativo.

A proposta é transformar dados de assinaturas em informações relevantes para o negócio, permitindo acompanhar o faturamento, entender o comportamento dos clientes e avaliar o desempenho dos diferentes planos.

## Objetivos da análise

- Analisar o faturamento total das assinaturas.
- Comparar o desempenho dos planos Core, Standard e Ultimate.
- Identificar a participação de cada plano no faturamento.
- Avaliar o impacto dos cupons de desconto nas vendas.
- Analisar a distribuição das assinaturas por periodicidade.
- Investigar a relação entre renovação automática e faturamento.
- Identificar a contribuição dos serviços adicionais EA Play e Minecraft.

## Estrutura do projeto

O arquivo Excel está organizado em quatro abas:

| Aba | Descrição |
|---|---|
| Assets | Paleta de cores e elementos visuais utilizados no dashboard. |
| Bases | Base de dados com informações dos clientes e suas assinaturas. |
| Cálculos | Tabelas dinâmicas utilizadas para responder às perguntas de negócio. |
| Dashboard | Visualização dos principais indicadores e resultados das análises. |

## Principais informações da base

A base de dados contém informações como:

- Identificação e nome dos assinantes.
- Plano contratado (Core, Standard e Ultimate).
- Data de início da assinatura.
- Renovação automática.
- Valor e periodicidade da assinatura.
- Contratação de serviços adicionais (EA Play e Minecraft).
- Valor dos cupons de desconto.
- Valor total da assinatura.

## Perguntas de negócio

O projeto utiliza tabelas dinâmicas para investigar questões relevantes, como:

1. Qual é o faturamento total das assinaturas por periodicidade?
2. Como o faturamento se distribui entre assinaturas com e sem renovação automática?
3. Qual é o volume de vendas dos serviços adicionais EA Play e Minecraft?
4. Qual plano apresenta a maior participação no faturamento?
5. Qual é o impacto dos cupons de desconto nas assinaturas?

## Dashboard

O dashboard apresenta indicadores e visualizações para facilitar a interpretação dos resultados, incluindo:

- Distribuição percentual do faturamento por plano (*Revenue Share by Plan*).
- Comparação entre quantidade de clientes e faturamento por plano (*Customers & Revenue by Plan*).
- Indicadores de desempenho das assinaturas.
- Análise da utilização de cupons de desconto.

## Ferramentas utilizadas

- **Microsoft Excel:** organização, tratamento e análise dos dados.
- **Tabelas Dinâmicas:** consolidação e exploração das informações.
- **Gráficos e Dashboard:** visualização dos indicadores e resultados.
- **Formatação condicional:** destaque visual de informações relevantes.

## Resultados esperados

O projeto busca demonstrar como ferramentas de análise de dados podem transformar uma base de informações em indicadores úteis para a tomada de decisão.

Através das análises, é possível identificar os planos com maior contribuição financeira, acompanhar a distribuição das assinaturas e compreender melhor os fatores que influenciam o faturamento.
