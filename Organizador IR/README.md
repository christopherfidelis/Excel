# Organizador de Informações para Declaração de Imposto de Renda

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma ferramenta em Excel para
centralizar, organizar e facilitar o controle de informações necessárias
para a declaração anual do Imposto de Renda Pessoa Física (IRPF).

A solução foi desenvolvida com foco em praticidade, organização e
validação de dados, proporcionando ao usuário um ambiente intuitivo para
registrar e consultar suas informações financeiras.

## Objetivo

Criar um agregador de informações que simplifique a organização dos
dados utilizados na declaração do Imposto de Renda, reduzindo a
dispersão de informações e facilitando o acompanhamento dos registros ao
longo do ano.

## Funcionalidades

-   **Centralização de informações:** organização dos principais dados
    necessários para a declaração do Imposto de Renda.
-   **Navegação intuitiva:** menus e atalhos para facilitar a utilização
    da ferramenta.
-   **Validação de dados:** aplicação de regras para minimizar erros
    durante o preenchimento.
-   **Automatização:** utilização de recursos do Excel para tornar o
    processo mais eficiente.
-   **Links rápidos:** acesso facilitado a informações e recursos
    externos relevantes.

## 🛠️ Tecnologias e recursos utilizados

-   Microsoft Excel
-   Validação de dados
-   Fórmulas e funções do Excel
-   Menus de navegação
-   Formatação e organização de planilhas

## Aprendizados

O desenvolvimento deste projeto permitiu colocar em prática
conhecimentos relacionados à organização e manipulação de dados no
Excel, construção de interfaces funcionais e documentação técnica.

Também proporcionou a oportunidade de utilizar o GitHub para
versionamento, documentação e compartilhamento do projeto.

## Estrutura do projeto

Os arquivos e materiais relacionados à ferramenta estão organizados
neste repositório.

## Como utilizar

1.  Faça o download dos arquivos disponíveis neste repositório.
2.  Abra a planilha no Microsoft Excel.
3.  Utilize o menu de navegação para acessar as funcionalidades.
4.  Preencha as informações solicitadas nos campos correspondentes.

------------------------------------------------------------------------

**Observação:** Esta ferramenta tem finalidade organizacional e de apoio
ao controle de informações. Ela não substitui a declaração oficial
disponibilizada pela Receita Federal.
